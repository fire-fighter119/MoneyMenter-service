## 更新

`index.html` と `styles.css` で構成した静的サイト。`main` ブランチのルートを GitHub Pages で公開します。依存ライブラリ・ビルド不要。

ブランドは青〜青緑、アイボリーとフクロウ＋¥・$のロゴで統一しています。料金・支払条件を変更する場合は、両サイトとLINEの案内を合わせて確認してください。個人の家計情報や相談記録は格納しません。

公式HPは、気軽に相談できる入口として整えます。個人の体験・資産形成の物語を前面に出さず、詳しい知識・考え方・できることの解説はMoneyMentorのnoteで扱います。HPには相談の進め方、料金、連絡先を簡潔に残します。
